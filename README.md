# Practical automation and data tools

I build small, focused tools that turn repetitive digital work into clear, repeatable workflows.

Current areas:

- Python automation and API integrations
- CSV cleanup, validation, and reporting
- opportunity research and transparent ranking
- technical documentation and quality checks

## Featured projects

- [Smart CSV Cleaner](https://github.com/sitemaster05/smart-csv-cleaner) — cleans inconsistent CSV files, removes duplicates, normalizes headers, and produces an audit report.
- [Opportunity Ranker](https://github.com/sitemaster05/opportunity-ranker) — ranks job and freelance opportunities against a real skill list and flags risky offers.

Every repository includes setup instructions, examples, and automated tests. AI-assisted tools may be used during development, but public work is reviewed and tested before release.

## Working approach

1. Confirm the scope and expected result.
2. Build the smallest useful version.
3. Test edge cases and document limitations.
4. Deliver reproducible files and clear handover notes.
